# Christmas Joke Advent Calendar

A 24-door advent calendar. Each day in December a new door unlocks with a kid-friendly Christmas joke.

- Works on older iPads and browsers (plain HTML, CSS and JavaScript, no build step).
- Doors unlock by the device's date. Add `#preview` to the end of the address to unlock every door for testing.
- To change the jokes, edit the `JOKES` list near the top of the script in `index.html`.

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
